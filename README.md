# 🎵 Spotify-Inspired Music Player UI

A responsive music streaming interface inspired by Spotify, built using **HTML** and **CSS**. The project recreates the overall layout and user experience while using custom assets and icons instead of official Spotify branding.

## ✨ Features

- Modern navigation bar
- Custom logo/icon
- Search bar with interactive hover effects
- Sidebar library section
- Playlist and podcast cards
- Music card layout
- Play button hover animation
- Smooth UI transitions
- Responsive Flexbox layout
- Dark theme inspired by Spotify

## 🛠️ Built With

- HTML5
- CSS3
- Font Awesome
- Google Fonts (Montserrat)
